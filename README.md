# Trainboard

Trainboard is a departure/arrival board for trains that uses real-time data from various data providers all across Europe.

Check it out at [https://trainboard.eu/](https://trainboard.eu/)

## Run this code

You can run this application locally by simply downloading the newest version from [Release Tab](https://github.com/opentransithub/trainboard/releases) and opening it in a web browser of your choice.
It's just JS :)

You need an internet connection to fetch data.

```
⚠️ PLEASE NOTE ⚠️
Trainboard v1.2.1 or higher is mandatory to run the application successfully. 
Older version might not longer work, due to changes in the requested APIs.

```

## Features
- Departure / Arrival Boards for trains and public transport
- Detailed Trip informations
  - Live data
  - Timetable informations
  - Vehicle informations
  - Carriage order
  - Connecting services
  - Detailed map view featuring mapbox 3D Layer
- Station search
  - Address
  - Surrounding map
  - Availability of facilities and services
  - Detailed escalatory elevator and accesibility status
  - Weather conditions
  - Google Maps Routing integration
- Other features
  - Various languages including English, German, French and spanish
  - 60+ available data providers
  - Station Favourites

## Contribution

If you wish to contribute to this project, please feel free to do so. However, it's important to keep in mind that the primary goal of this project is to faithfully replicate the "Mit-Tog" WebApplication offered by BaneDanmark. ([Reference](https://www.mit-tog.dk/en))

Therefore, if you intend to make functional or visual changes that deviate from the original purpose, consider creating your own project using the code provided here.

```
Please be aware that one of the significant advantages of this application
is its ability to run locally in a webbrowser without requiring a complicated setup.
Preserving this functionality would be highly appreciated :)
```
